AF‑OS  ·  Simulation, not an operating system

A desktop built to walk you through the work, not link you away from it.

Most of what I build lives on the live web already. Rather than send you to a README and a list of repos, this simulates the desktop it would sit on — icons you open, windows you drag, a taskbar that actually runs something.

It's a portfolio wearing an OS as a shell. Everything you can click opens a real project, live, in its own window.

⚠ Built for laptop/PC screens — this experience is not designed for mobile viewing.
